# Astra 품질 수정 공지와 GroundLine 최종 점검

확인일: 2026-09-12. 점검 기준 소스: `d61d9a0` / 설치: Core `0.25.5`.

현재 설치에서 모델·추론 설정 충돌이나 관련 지침 누락은 확인되지 않았다.
이번 보완은 재개 시 과도한 스킬 호출과 검증 횟수 제한으로 읽힐 수 있는
표현을 바로잡는다. 실제 조기 종료를 재현한 버그 수정이나 모델 성능 향상
측정으로 해석하지 않는다.

## 공지에서 확인한 내용

[Tibo의 9월 12일 공지](https://x.com/thsottiaux/status/2098612714704891959)는
이전 모델용 일부 스킬의 과도한 호출·검증 방해, 조기 종료나 이전 메시지
응답을 일으킨 선택적 컨텍스트 실험 중단, 품질 저하를 일으킨 일부 서버
엔진 설정 제거를 설명한다. 모델 가중치 변경 여부, 개별 계정의 엔진 배치,
이 호스트의 과거 실험 참여 여부는 이 공지로 확인할 수 없다.

[현재 Astra 가이드](https://developers.openai.com/api/docs/guides/latest-model#prompting-best-practices)는
지침 충돌 점검, 승인된 작업의 지속, 변경에 맞는 검증을 권장한다.
[Codex 0.154.0 변경 기록](https://learn.chatgpt.com/docs/changelog)은 플러그인
갱신 후 스킬·훅 반영과 압축 후 승인 맥락 보존 수정도 명시한다. 이 기록은
9월 12일 서버 변경이 특정 설치에 적용됐다는 증거와 구별한다.

## 변경과 확인 기준

- 저장소 지침은 현재 증거와 다음 행동이 명확한 재개 작업에서 점검 스킬을
  다시 요구하지 않는다.
- 정렬 스킬과 모델 가이드는 필요한 검증을 완료하고 유효한 결과를 재사용한다.
  작은 변경·토큰 절약을 검증 생략 사유로 삼지 않는다.
- 설치 점검은 스킬 과잉 호출과 검증 억제를 함께 찾는다. 컨텍스트 진단은
  실험 상태와 일반 압축을 구분하고 일시적 장애를 영구 기본값으로 만들지 않는다.
- [행동 검증 사례](../guidance-validation.md)에 재개, 검증 생략, 오래된 통과
  결과, 컨텍스트 실험 공지에 대한 기대 행동을 추가한다.

검증 결과:

- `cargo test --locked -p xtask guidance::tests`: 12개 통과.
- `cargo run --locked -p xtask -- verify-source --root . --json`: `PASS`.
  스킬 메타데이터·링크와 소스 경계 통과, 모델 행동 평가는 `not_run`.
- `git diff --check`: 통과. 개인 설정의 수정 전후 SHA-256 일치.

문구를 그대로 검사하는 테스트나 새 모델 호출은 추가하지 않았다. 원본·설치
비교와 설정 진단은 읽기 전용이며 모델, 추론, 서비스 티어를 변경하지 않았다.

이번 기록은 지침 소스와 현재 설치의 점검 결과다. 새 지침의 공개 배포·설치,
실제 Astra의 완료율·재작업·토큰 변화, 서버 엔진 수정의 계정별 적용은
**UNVERIFIED**다. NAS와 수집 데이터는 이번 변경의 대상이 아니다.
