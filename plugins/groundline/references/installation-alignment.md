# Requested installation diagnosis

This is manual maintenance, not a prerequisite for workflow improvement. Resolve
the current App-bundled CLI and enabled plugin through [platform commands](platform-commands.md).
Use `doctor --json` for a bounded local diagnosis and `provider-smoke
--plugin-root ROOT --require-installed --json` for native package integrity.
Neither command establishes useful guidance exposure or behavioral improvement.

Use the documented native installer only for a requested installation/update.
Preserve user choices, disabled plugins, identity, collection and consent.
[Configuration](codex-configuration.md) describes explicit setup or repair;
[native upgrade](native-upgrade.md) describes the supported update path.
Do not register an environment baseline, enable a learning profile, add hooks,
reset historical records or run model experiments to complete installation.
